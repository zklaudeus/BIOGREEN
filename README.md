
# BIOGREEN — Sitio web empresarial

Sitio web corporativo para una empresa dedicada a la gestión y valorización de residuos orgánicos.

## Demo en vivo
🌐 [Visitar sitio web](https://biogreenrecicla.cl/)

## Tecnologías
- Astro 6
- Tailwind CSS 4
- TypeScript / JavaScript
- Vercel

## Funcionalidades
- Diseño responsive
- Presentación de servicios de compostaje
- Información corporativa
- Navegación y contacto

## Objetivo
Ofrecer una presencia digital profesional para presentar los servicios de BIOGREEN y facilitar que potenciales clientes conozcan la empresa.
